# OMEGA v1.0.2 — Puente táctil experimental Android

No es una aplicación separada. Se añade AccessibilityService con BIND_ACCESSIBILITY_SERVICE y dispatchGesture, consentimiento explícito del usuario en Ajustes, un gesto pendiente, coordenadas normalizadas, duración y vigencia máximas 500 ms y verificación del paquete de la ventana activa. No se conserva contenido textual. No se intenta habilitar el permiso automáticamente. El servicio no se arma sin adaptador privado atestado y sesión de captura permitida; al detener, perder recursos o interrumpir se desarma. Una acción ya entregada al sistema puede terminar; no se promete revocación instantánea del gesto en curso. El callback informa entrega, no éxito de una acción del juego.

El cliente público com.dts.freefireth se excluye de la ruta táctil experimental; la apertura normal v1.0.1 se conserva. GameBinding.adapter sigue null. No se añaden coordenadas de HUD, interpretación de controles ni bot de partidas. El contrato GamePort sigue requiriendo un adaptador real para convertir ofertas válidas en gestos y confirmar efectos. No se ha comprobado ninguna autorización del proyecto G-AI, ni paquete privado, ni firma, ni partida. No se solicita activar accesibilidad mientras no exista ese adaptador. No hay pruebas de dispositivo físico. La prueba host comprueba la lógica pura de caducidad, límites y alcance; CI comprueba compilación Android.

Fuentes: https://developer.android.com/guide/topics/ui/accessibility/service y https://support.google.com/googleplay/android-developer/answer/10964491?hl=es. Google Play restringe agentes autónomos que usan AccessibilityService. Una distribución interna y el permiso del propietario son asuntos separados de las políticas de publicación.
