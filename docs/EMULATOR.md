# Android emulator smoke (v1.0.12)
The emulator-only ABI is selected via -PomegaEmulator=true; the normal phone build remains arm64-v8a. The separate Android API 33 virtual device test installs OMEGA and an instrumentation APK, starts/stops the JNI core, checks unauthorized capture rejection, connects the accessibility service, attaches and removes the real overlay in OMEGA's own activity, verifies start is rejected outside the game, and runs the actual bundled YOLOX and ML Kit models on a generated test image. Screenshots, logcat and instrument output are archived. This test does not install Free Fire, impersonate its package, send gestures to it or attest that movement/pause/resume works in the official game. The test APK is not intended for Samsung installation. The production build workflow and arm64 ABI remain unchanged.

First emulator run 46033933530: app launch and JNI lifecycle passed. Logcat reported IllegalStateException: Overlay not attached at OmegaEmulatorTest.kt:54, from assertion in Instrumentation.SyncRunnable immediately after addView. Test now waits for actual attach/layout across UI traversals, catches UI exceptions on the UI thread and reports them on the instrumentation thread, and cleans up before finish. This is a test synchronization fix, not evidence of a production overlay defect. Crash buffer and OMEGA-specific log lines are exported. New run required for verification.

Extended test: 45 seconds of repeated vision frames at 1 Hz, with YOLOX, OCR and HUD lanes active together. Reports per-lane completion counts, latency min/median/max, stale OCR/HUD at first read, and fraction of samples with both timing windows satisfied. Test image is generated text, not a game screenshot. Also tests thermal policy using controlled inputs (not physical heating). No production changes; does not validate gameplay actions or physical thermal behavior.

Baseline run 46039445765: OCR median 5687ms, 7/7 stale, simultaneous freshness 0/433. OCR optimization reuses a full-resolution bitmap and uses a single-entry exact-pixel cache with an eight-second age bound from original model input and lane-generation invalidation. No approximate matching, cropping, resolution loss or relaxed freshness limit. Test distinguishes cache hits from real inference and measures distinct text separately. No game or physical device validation.

Run 46042416416: static median 20ms (7 cache hits, 5 real model calls), 5/12 stale; simultaneous freshness 139/435; dynamic model-only median 3072ms. Crash buffer empty. Dynamic test formerly used snapshot TTL of 4s and labeled content match as fresh even beyond the adapter's 2500ms requirement. Now waits for published completion, matches exact submitted frame, logs age and fresh2500 separately. OCR now trims exact uniform outer margins only when sufficient area savings, preserves every non-background pixel at original resolution, remaps coordinates, falls back to full frame on empty output. Nonuniform scenes may receive no speedup; accuracy and latency must be measured, no timing gate relaxation.

Thermal policy revision: Android status 3 alone selects ECONOMY rather than LIMITED. Training capture and OCR remain enabled and bounded gestures are eligible when the independent battery, memory and authorization checks pass; depth and online learning remain disabled in ECONOMY. Android status 4+ and battery temperature 47C still latch STOP; battery 43C still selects LIMITED. No OS thermal changes. Tests cover the reported low-heap thermal=3 case with a normal battery temperature; user log did not include actual battery temperature. Runtime diagnostic now includes battery temperature, charge and performance counters.
