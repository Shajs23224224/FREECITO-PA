# Android emulator smoke (v1.0.12)
The emulator-only ABI is selected via -PomegaEmulator=true; the normal phone build remains arm64-v8a. The separate Android API 33 virtual device test installs OMEGA and an instrumentation APK, starts/stops the JNI core, checks unauthorized capture rejection, connects the accessibility service, attaches and removes the real overlay in OMEGA's own activity, verifies start is rejected outside the game, and runs the actual bundled YOLOX and ML Kit models on a generated test image. Screenshots, logcat and instrument output are archived. This test does not install Free Fire, impersonate its package, send gestures to it or attest that movement/pause/resume works in the official game. The test APK is not intended for Samsung installation. The production build workflow and arm64 ABI remain unchanged.
